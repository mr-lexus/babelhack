# Участие в Babel Hack

Установка среды и проверки описаны в [README](README.md) и [PLATFORMS](docs/PLATFORMS.md). Используйте Node.js 22+ и Rust stable, устанавливайте npm-зависимости через `npm ci`. Сохраняйте оба lockfile.

Перед pull request запустите форматирование, frontend build, Playwright, Rust tests и Clippy. Сетевые и аппаратные тесты с `--ignored` запускаются явно; обычные тесты не должны расходовать API-баланс или записывать личный звук.

В issue указывайте версию приложения, ОС/архитектуру, шаги воспроизведения и ожидаемое поведение. Не прикладывайте API-ключи, личные транскрипты, `.env` или рабочий профиль. Для воспроизведения используйте демо/синтетический звук.

Изменения переводческого pipeline должны сохранять порядок финальных реплик, исходник при ошибке перевода и ограниченное завершение задач. Обновления оверлея должны затрагивать только изменившиеся React-подписки. Сохраняйте доступные имена элементов и клавиатурное управление.

Вклад распространяется по [Apache-2.0](LICENSE). Лицензии и уведомления сторонних компонентов должны сохраняться.
