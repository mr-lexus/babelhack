# Безопасность

Для непубличного сообщения об уязвимости используйте [GitHub private vulnerability reporting](https://github.com/mr-lexus/babelhack/security/advisories/new). Не публикуйте ключи и личные разговоры в issue. Если форма недоступна, сначала создайте issue с просьбой о приватном канале без деталей уязвимости.

API-ключи хранятся в системном credential store. Аудио отправляется Deepgram; текст, контекст и словарь — OpenAI. История локальная и не шифруется приложением. Демо не отправляет данные этим сервисам. Обработка сервисами зависит от настроек вашего API-аккаунта.

Разрабатывается последняя версия 0.x; исправления выпускаются в новых версиях. Публичные пакеты пока без подписи проверенного издателя (macOS ad-hoc, без notarization). Проверяйте SHA256SUMS и скачивайте из официального репозитория.

`npm audit` и `scripts/audit-rust-dependencies.py` помогают проверять зависимости. Локальный GLib backport описан в `src-tauri/vendor/glib/PATCHES.md`. Обнаружение нового advisory требует оценки фактического пути исполнения; отсутствие отчёта не гарантирует отсутствие проблем.
