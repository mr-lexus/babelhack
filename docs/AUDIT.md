# Аудит Babel Hack: журнал изменений

Текущий публичный выпуск — 0.7.0. В 0.5 переработана сборка цельных предложений (вместо коротких чанков 0.4), в 0.6 добавлен трей, в 0.6.1 исправлена двойная рамка оверлея Windows. В 0.7 добавлены бренд Babel Hack, Apache-2.0 и публикация пяти нативных целей, включая Linux ARM64. Текущие правила: [LIVE_TRANSLATION.md](LIVE_TRANSLATION.md), [TRAY.md](TRAY.md), [PLATFORMS.md](PLATFORMS.md).

Ниже сохранён исторический отчёт: числа тестов, аудит зависимостей и ограничения относятся к указанным версиям, а не автоматически к текущему релизу. Свежие результаты находятся в [GitHub Actions](https://github.com/mr-lexus/babelhack/actions).

## Архив аудита 0.2

Продолжение 0.4: перевод промежуточных гипотез до завершения речи, короткие подтверждённые чанки, отмена устаревших запросов и переиспользование совпавших переводов. Оверлей использует независимые React-подписки и постоянные ID строк; лишние commit проверены профилировщиком. Исследование, API-замеры и ограничения — [LIVE_TRANSLATION.md](LIVE_TRANSLATION.md).

Продолжение 0.3: реализованы платформенные адаптеры Windows/macOS/Linux, системные хранилища ключей, stable device IDs и CI для четырёх нативных целей. На Windows прошли 30 модульных тестов; UI проверен в Chromium и WebKit. GLib для Linux теперь использует локальный backport исправления RUSTSEC-2024-0429. Подробности и границы фактической проверки — [PLATFORMS.md](PLATFORMS.md). Остальной текст ниже фиксирует аудит версии 0.2.

Дата: 3 октября 2026. Объём: Rust backend, аудиопоток, Deepgram/OpenAI, управление задачами, окна Tauri, React UI, хранение, секреты, экспорт, сборка и документация.

| Высокий | Завершение потока STT и сетевые сбои могли оставить программу зависшей или молча переставшей работать | Явная обработка EOF/Close/Error, управляемое WebSocket-соединение, reconnect, KeepAlive и таймауты |
| Высокий | При ошибке переводчика исходная реплика терялась из пользовательского результата | Оригинал сохраняется до запроса, ошибка привязана к фразе; незавершённые записи отмечаются |
| Высокий | Частично успешная миграция секретов могла убрать из конфига оба ключа | Каждый ключ очищается независимо, только после успешной записи в Credential Manager |
| Средний | rustls 0.23.43 затронут RUSTSEC-2026-0285, ошибка обработки границ шифрования TLS 1.3 | Обновлён Cargo.lock до исправленной версии 0.23.45 |
| Средний | Неограниченный аудиоканал, ошибки устройства без нормального восстановления | Буфер на 2 секунды, счётчик потерь, видимая ошибка, переоткрытие при продолжении |
| Средний | Отсутствующее выбранное устройство молча заменялось другим | Явная ошибка и выбор устройства в настройках |
| Средний | Текущая фраза попадала в предыдущий контекст, пустой endpoint не завершал стабильный текст | Разделение контекста и текущего сегмента; обработка пустых финалов и сохранение незавершённого хвоста |
| Средний | Snapshot субтитров отсутствовал; перезагрузка окна очищала текст | Общий Runtime, события с версиями, подписка до snapshot, периодическая сверка |
| Средний | Ограничения истории и настроек субтитров расходились, текст обрезался | Единый диапазон 1–8 фраз, полный текст, прокрутка |
| Средний | Конкурирующие записи настроек и геометрии, физические координаты вместо логических | Mutex, атомарная запись, отдельное сохранение геометрии, DPI и проверка монитора |
| Средний | Настройки в отдельном окне можно было закрыть без понятного восстановления | Настройки внутри главного окна, сохранение черновика при переходах |

## Зависимости Rust

Через OSV проверены 550 registry-пакетов из Cargo.lock. Обнаруженная [уязвимость rustls RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285.html) исправлена обновлением 0.23.43 → 0.23.45; повторный запрос OSV больше её не возвращает.

Оставшиеся замечания не скрыты:

- glib 0.18.5: [RUSTSEC-2024-0429](https://rustsec.org/advisories/RUSTSEC-2024-0429.html), ошибка безопасности памяти. Пакет присутствует в общем lockfile, но cargo tree для x86_64-pc-windows-msvc подтверждает отсутствие в дереве Windows-сборки. Это ограничение при будущем переносе на Linux.
- proc-macro-error 1.0.4: [RUSTSEC-2024-0370](https://rustsec.org/advisories/RUSTSEC-2024-0370.html), библиотека не поддерживается; также отсутствует в дереве целевой Windows-сборки.
- Пять пакетов unic-* 0.9.0: уведомления о прекращении поддержки, включая [RUSTSEC-2025-0100](https://rustsec.org/advisories/RUSTSEC-2025-0100.html). Входят транзитивно через tauri-utils → urlpattern. Исправленных версий unic-* нет; замена требует изменения upstream-зависимости Tauri, принудительно несовместимая версия в этот выпуск не добавлялась.

Воспроизводимый сканер: scripts/audit-rust-dependencies.py. Полный JSON-результат: artifacts/rust-osv-audit.json. Эти результаты не означают отсутствие неизвестных уязвимостей и не заменяют обновление зависимостей после выпуска.

## Практические ограничения

- Сетевая потеря звука необратима; нет локального резервного распознавания.
- Live-запросы проверены на коротком синтетическом примере. Нет подтверждения для всех языков, моделей, гарнитур, Bluetooth-переключений и многочасовых звонков.
- Нативный диалог сохранения и установка/удаление NSIS требуют отдельного ручного прогона; генерация экспортируемого содержимого и браузерная загрузка проверены.
- Установщик не подписан сертификатом разработчика. Не выполнена матрица чистых Windows 10/11 и систем без WebView2.
- История — локальные JSON-файлы без шифрования. Звук отправляется Deepgram, текст — OpenAI; офлайн-режима нет.
- Законченные сегменты переводятся последовательно; при медленном API появляется очередь. Размер очереди и время ожидания ограничены, перегрузка сообщается пользователю.
- Нет захвата отдельного приложения/микрофона, идентификации спикеров, календарного бота, голосового дубляжа или серверной синхронизации.
