# Цельные субтитры — Babel Hack

## Причина

Версия 0.4 разрезала подтверждённый текст каждые 12 слов, после запятых и по возрасту буфера 1,2 секунды, даже при продолжающемся interim. Каждый кусок отдельно переводился и становился строкой истории. Зависимые части теряли общий контекст. Изменение line-height этого не исправляло.

## Исследование (3 октября 2026)

- [Google Translate](https://research.google/blog/stabilizing-live-speech-translation-in-google-translate/): повторный перевод растущего предложения, задержка нестабильного хвоста и предпочтение показанной формулировки уменьшают переписывание текста.
- [Deepgram](https://developers.deepgram.com/docs/understand-endpointing-interim-results): is_final фиксирует отрезок распознавания; speech_final сообщает о паузе. Подтверждённые отрезки необходимо соединять.
- [Amazon Transcribe](https://docs.aws.amazon.com/transcribe/latest/dg/streaming-partial-results.html): стабильные слова отделяются от изменяемого хвоста; ранняя фиксация ускоряет результат ценой точности.
- [Microsoft Azure](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/captioning-concepts): ожидание устойчивых промежуточных результатов уменьшает мерцание, добавляя задержку.

Использованы принципы, а не закрытые реализации Google/Teams/Windows. previous_translation в Chat Completions — подсказка модели, а не аналог управления её decoder.

## Реализация

ASR final добавляется к открытому предложению; interim заменяет только неустойчивое продолжение. Перевод получает всё предложение. Короткий endpoint и UtteranceEnd больше не создают историю. Пустые служебные пакеты не обновляют часы речи.

Терминальная пунктуация подтверждается следующей самостоятельной фразой либо 650 мс без нового текста. Короткие отрывки, сокращения и явные продолжения объединяются. Без пунктуации ожидание составляет 1800 мс. При открытом interim таймер не отделяет стабильное начало. Защитный предел монолога — 72 слова / 600 символов на границе подтверждённого ASR-пакета; сам пакет повторно не режется. Stop/disconnect сохраняет подтверждённый остаток и отдельно помечает неподтверждённый хвост.

Один активный запрос, FIFO финалов до 32, watch последней гипотезы, интервал предварительных запросов 750 мс. Последние два слова черновика (CJK: четыре символа) задерживаются. Дополнение выводится целыми словами; переписанное начало заменяется только по завершении ответа. Показанный черновик передаётся модели для сохранения формулировки, но исправления смысла имеют приоритет. Совпавший финал принимает готовый или текущий предварительный запрос.

Таймаут, сетевой сбой или HTTP 5xx финала допускает один повтор: 10 с на попытку, пауза 250 мс. У черновика бюджет 5 с без повтора. Остановка отменяет запрос. После неудачи оригинал остаётся на своём месте с явной пометкой, подробности ошибки — в истории. Следующий успешный перевод снимает предупреждение, не затрагивая другие статусы.

React: отдельные useSyncExternalStore-подписки; сохранение ссылок cue, включая untranslated; memo и постоянные ID. Готовые абзацы не перерисовываются при изменении черновика. CSS переносит строки внутри абзаца. Ручное чтение истории не прерывается автопрокруткой.

## Проверка

Регрессии: пример из пяти частей про глубокий сон/память, однословные пакеты, паузы, непрерывный interim, отрицание, повторы, Unicode, сокращения, остановка, сбои и восстановление.

Сетевой live_coherent_sentence_replay: в первом прогоне черновик на 1110 мс, закрытие фразы на 11231 мс, финал на 11934 мс. Пять фрагментов дали одно русское предложение. Это замер после подачи текста, без STT/захвата; журнал artifacts/coherent-replay.json.

live_coherent_audio_pipeline: синтетический WAV передаётся в Deepgram с реальным темпом PCM, результаты и таймеры проходят тот же reconciler, собранные фразы переводятся OpenAI. Четыре ASR-final пакета дали два целых предложения за 18,56 с, включая передачу аудио. Подтверждённые слова не потеряны и не продублированы. Журнал artifacts/coherent-audio-replay.json. Личное аудио не захватывается.

Playwright: React commits/DOM, устаревшие события, длинные абзацы при 420/1100 px, пометки ошибок и чтение истории во время обновлений, Chromium и WebKit. Нативный Windows проверяется в отдельном профиле.

Повтор сетевого аудиотеста в Windows:

```powershell
powershell -NoProfile -File scripts/generate-smoke-audio.ps1 -Coherent
cargo test --manifest-path src-tauri/Cargo.toml --lib live_coherent_audio_pipeline -- --ignored --nocapture
```

## Ограничения

Границы — эвристика, не семантический классификатор. Длинная пауза внутри мысли, неверная пунктуация ASR и очень длинные предложения могут дать спорную границу. Предварительный перевод продолжает работать, пока ждём границу. Сеть и модель влияют на задержку; замеры не являются гарантией. Предварительные запросы увеличивают расход API. WebKit не заменяет нативные проверки macOS/Linux.
