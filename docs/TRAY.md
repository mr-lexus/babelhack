# Системный трей — Babel Hack

Tauri 2 TrayIconBuilder с тем же значком приложения. Меню: статус, показать окно, скрыть в трей, переключить субтитры, начать/приостановить/продолжить перевод, завершить сессию, настройки, выход. Старт перевода доступен только по явному выбору пользователя; фонового запуска записи нет.

Windows: левая кнопка значка возвращает главное окно, правая открывает меню. macOS/Linux: меню открывается нажатием значка, возврат через «Показать окно». Меню меняется только при переходе состояния сессии, а не при каждом слове. Неактивная сессия отключает «Завершить».

Настройки close_to_tray и minimize_to_tray независимы и сохраняются. Крестик Windows/macOS по умолчанию скрывает окно, обычное сворачивание остаётся стандартным. На Linux close_to_tray по умолчанию false: рабочее окружение может требовать AppIndicator-расширение. Если создать трей не удалось, скрытие недоступно, крестик/сворачивание сохраняют стандартное поведение.

Главное окно скрывается, а не уничтожается: перевод, история, черновик настроек и оверлей продолжают работать. Оверлей уже исключён из панели задач. macOS дополнительно скрывает Dock-значок при уходе в трей и восстанавливает его при возврате. Dock Reopen также возвращает главное окно.

«Выйти из приложения» и системный Quit всегда вызывают единый begin_exit: прекращение захвата, ограниченное ожидание распознавания/перевода и сохранение истории. Настройка крестика не препятствует явному выходу. Повторные запросы выхода не запускают второй shutdown. Новая сессия не стартует при выходе.

## Проверено

Windows EXE 0.6.0, отдельный профиль. scripts/smoke-tray.mjs и scripts/native-tray-menu.ps1 открывают реальное Windows-меню принадлежащего тестовому процессу значка, читают названия и доступность пунктов и вызывают их нативные команды. Проверяются работа перевода после скрытия, повторный возврат, кнопки заголовка, native CloseRequested, пауза/продолжение, субтитры, настройки, сохранение поведения сворачивания после reload, нативное сворачивание, завершение и явный выход при скрытом активном окне. Сценарий использует демо, не личный звук.

Запуск требует NATIVE_TEST_PROFILE=1, NATIVE_TEST_PID=<PID изолированного EXE>, NATIVE_PWSH=<путь к PowerShell 7> и WebView2 CDP 9224. Не запускать против рабочего профиля пользователя.

macOS/Linux реализованы общим Tauri API с платформенными ветками, но нативные проверки требуют соответствующих хостов. Linux runtime-зависимости AppIndicator добавлены в deb/rpm, build-зависимость уже есть в CI.

Справочник API проверен через Context7: [Tauri system tray](https://v2.tauri.app/learn/system-tray/).
