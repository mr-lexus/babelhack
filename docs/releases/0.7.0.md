Первый публичный выпуск **Babel Hack** — живой перевод системного звука с субтитрами поверх любого приложения.

### Возможности

- Deepgram → OpenAI: потоковое распознавание, растущий перевод и цельные подтверждённые фразы.
- Настраиваемый оверлей, компактная история, собственная рамка и системный трей.
- Словарь терминов, выбор языков, пауза/продолжение, локальная история и экспорт TXT/Markdown/JSON.
- Ключи в системном хранилище. Демо работает без API-аккаунтов.
- Apache License 2.0. Прежние настройки, история и ключи Interview Translator совместимы.

### Загрузки

| Система | Выберите файл |
|---|---|
| Windows 10/11 x64 | windows-x64-setup.exe; отдельный windows-x64.exe требует WebView2 |
| macOS 14.6+ Intel | macos-x64.dmg или macos-x64.app.zip |
| macOS 14.6+ Apple Silicon | macos-arm64.dmg или macos-arm64.app.zip |
| Linux x64 | linux-x64.deb / .rpm / .AppImage |
| Linux ARM64 | linux-arm64.deb / .rpm / .AppImage |

Полные имена начинаются с BabelHack-0.7.0-. Контрольные суммы: SHA256SUMS.txt.

### Перед запуском

Интерфейс пока на русском. Нужны собственные оплачиваемые ключи Deepgram и OpenAI; подписка ChatGPT не заменяет OpenAI API. Аудио отправляется Deepgram, текст и контекст — OpenAI. История локальная, без шифрования приложением.

Windows без Authenticode; macOS с ad-hoc подписью, **без notarization**: возможны предупреждения ОС. На Mac перенесите .app в Applications, при необходимости разрешите открытие через Privacy & Security, затем выдайте разрешение на системный аудиозахват. На Linux нужны PulseAudio/pipewire-pulse, пользовательская D-Bus-сессия и Secret Service; трей может требовать AppIndicator.

Все пять целей проходят нативную сборку и Rust-тесты. Chromium/WebKit проверяют интерфейс; Linux дополнительно проверяет виртуальный audio monitor и Secret Service. Это не подтверждение всех драйверов, macOS-разрешений и Wayland-сред: проверки на реальных устройствах продолжаются. На macOS оверлей непрозрачный, Wayland управляет размещением окон.
